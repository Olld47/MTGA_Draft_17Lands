===================== RELEASE NOTES 1.0 =====================
### Highlights

#### 桌面版正式发布

MTGA 轮抓工具桌面版（React + TypeScript + Tauri 2 + 内嵌 Python）正式发布，是**唯一客户端**：`main.py` 是已构建桌面版的便捷启动器（透传 `-f`/`-d`），旧版 tkinter 界面已随本版本**移除**，不再存在 `--ui` / `default_ui` 切换或源码回退。桌面为唯一演进线。

#### 完整功能对齐

桌面版对齐全部核心功能：实时轮抓面板 + 组合引擎建议（Compositional Brain v5.5，Z-Score 强度 / 颜色通道 / 曲线需求 / 轮抓概率加权 0-100 VALUE 评分）、AI 蒙特卡洛套牌优化（10,000 场模拟）、现开工作室（Sealed Studio，AI 框架生成器）、赛后复盘、信号检测、轮抓历史与悬停卡图统计。全站中文界面（菜单 / 页面汉化、设置页语言切换），PickTwo 双抓与 Contender Draft 完整支持。

#### 轮抓可靠性提升

轮抓断线重连不再丢状态：信号保留、recap 判定、eventid 验证（v0.35）；重连后日志切换器自动选中最新轮抓记录（v0.39）。数据集自动同步每日云端 ETL 遥测，数据集页显示最后同步时间与陈旧警告（>7 天），同步失败次日自动重试并 toast 提示。

#### 架构评审 12 项全部落地

ArenaScanner 显式状态机与持久化抽取（DraftSession）、引擎参数单源、七个模块收敛到 src 纯层共享、进程级可变状态收敛、同步失败可观测、tkinter 测试污染根除、常量与命令拆分——架构评审 12 项全部 resolved，全套 Python 测试 1924 passing，前端 vitest / tsc 干净。

#### Desktop Release

The desktop app (React + TypeScript + Tauri 2 + embedded Python) is now the **only client**. `main.py` is a convenience launcher for the built binary (forwarding `-f`/`-d`); the legacy tkinter UI was **removed** with this release — no `--ui` / `default_ui` switching, no source fallback. The desktop is the sole evolution line.

#### Full Feature Parity

Live pack panel with the Compositional Brain v5.5 advisor (0-100 VALUE scores from Z-score power, color lane, curve needs and wheel probability), AI Monte Carlo deck optimizer (10,000 simulated games), Sealed Studio with AI shell generator, post-draft recap, open-lane signal detection, draft history and hover tooltips with 17Lands stats. Full Simplified-Chinese UI with language switching, PickTwo and Contender Draft support.

#### Draft Reliability

Reconnect no longer loses state: signals, recap decisions and event-id validation survive log switches (v0.35); the log switcher auto-selects the newest draft session after reconnect (v0.39). Cloud datasets sync daily from the ETL pipeline, with last-sync dates and stale warnings (>7 days) on the Datasets page; failed syncs retry on next launch with a toast.

#### Architecture Review Complete

All 12 architecture-review items resolved: explicit scanner state machine and persistence extraction (DraftSession), single-source engine parameters, seven modules converged into shared pure-layer code, process-global state eliminated, sync-failure observability, tkinter test-pollution fix, constants/commands split. Full Python suite 1924 passing; frontend vitest/tsc clean.
